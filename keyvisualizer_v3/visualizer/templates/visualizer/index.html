📦 Vial ZIP Downloaded — How to Compile

Follow these steps to build and flash your Vial firmware.

STEP 1 — Clone vial-qmk (once)
git clone https://github.com/vial-kb/vial-qmk.git
cd vial-qmk && make git-submodule
⚠️ Keep outside your existing qmk_firmware folder.
STEP 2 — Copy keyboard folder
cp -r custom_handwired/ vial-qmk/keyboards/handwired/
Extract the ZIP first.
STEP 3 — Verify environment
cd vial-qmk && qmk doctor
STEP 4 — Compile
make handwired/custom_handwired:vial
Use make, not qmk compile.
STEP 5 — Flash
make handwired/custom_handwired:vial:flash
Or flash the .uf2/.hex via QMK Toolbox.
💡 After flashing: Open Vial GUI → auto-detected. Use Security → Unlock (hold top-left 2 keys ~3s) before editing.
